## PLAT-20261029-03 · 작성 계정 경계·댓글 복구

상태: 구현·자체 검증·독립 검수 통과, 운영 미적용. 서명된 작성 계정 컨텍스트로 계정 전환 시 초안의 다른 계정 저장을 차단하고 동일 계정 재로그인 복구를 지원한다. 댓글 실패 입력 복구와 공통 검색 Enter 처리도 적용했다. 전체 326건·브라우저 11개 흐름·독립 19건 통과. 구 JS의 stale CSRF 갱신 차단 및 직접 API 호환, 검증 증거·한계·운영 상태는 [주관 대장](platform.md#plat-20261029-03)을 따른다. DB 구조·모델·PDF 본문 변경은 없다.

<a id="plat-20261029-review-03"></a>
## 2026-10-29 추가 검수

R2~R5 보완은 유지된다. 추가 P2는 계정 전환 후 옛 신규 작성 탭의 CSRF 자동 재시도가 다른 계정으로 초안을 저장하는 R6, 검사 메모·댓글 DB 조회 장애의 입력 복구 누락 R7이다. 다른/같은 계정 브라우저 대조와 신규/수정 HTTP를 실제 실행했고 제품 코드는 수정하지 않았다. 공통 포함 전체 발견 3건과 집중 43건 검증·미실행 범위는 [추가 검수 대장](platform.md#plat-20261029-review-03)을 따른다.

<a id="plat-20261029-02"></a>
## PLAT-20261029-02 · K-HTP 저장 상태·일정 연결 보완

상태: 구현·자체 검증·독립 재검수 통과, 운영 미적용. 대상자 재선택 시 공통 연결 정리를 적용하고, 업로드·저장·분석·PDF 실패 복구의 응답 요약을 저장 트랜잭션 안에서 준비한다. 후속 조회 실패 때문에 이미 저장한 신규 기록을 failed로 안내해 재시도 시 중복 생성하는 문제를 보완했다. 분석 2단계와 PDF 생성 실패는 실제 커밋된 사본·개정으로 복구하며 다른 요청과 충돌하면 오래된 사본을 최신 결과로 반환하지 않는다. 전용 11건을 포함해 전체 311건 및 격리 PostgreSQL 보완 25건을 통과했다. 실제 업로드 실패/단일 재시도와 저장·재열기·K-HTP PDF 5쪽도 확인했다. 독립 검수 29건 통과·추가 필수 수정 0건이다. 추론은 mock으로 모델 성능 검증이 아니다. 계약과 전체 검증/운영·복구 상태는 [공통 변경 기록](platform.md#plat-20261029-02)을 따른다. 새 스키마·모델·PDF 내용 변경은 없다.

<a id="plat-20261029-01"></a>
## PLAT-20261029-01 · 2026-10-29 · K-HTP 연동

상태: 구현·격리 검증·독립 리뷰 통과, 운영 미적용. 주관: 공통 기반. [계약 원본](../ssot/08-people-scheduler.md). 대상자 코드·검색·수동 병합, 검사/일정 연결, 일정 공유·댓글, 관리/기능 스위치와 TCI 저장 보호를 추가했다. 기존 검사 계산·본문·그림·PDF·소유권은 보존한다. 병합 시 충돌 방지용 시각/개정만 갱신한다.

영향: UI·DB·API·권한 변경 있음, 원본 자료·PDF 생성 형식 변경 없음. 새 의존성 없음. 새 레이아웃 Flexbox, 추가 아이콘 없음. 전체 회귀 286건과 독립 집중 50건, 격리 DB/브라우저/PDF 검증을 통과했다. Git 커밋/푸시, 운영 이관/배포 미실행. 복구는 서비스 중지 후 코드와 배포 전 DB 백업의 함께 복원이며 자동 downgrade는 없다.

검증 상세·R1 보완·증거·제한은 [공통 변경 대장](platform.md#plat-20261029-01)을 따른다.

관리: K-HTP 익스큐트(Astra) / 오케스트라 · 계약: [K-HTP SSOT](../ssot/06-khtp.md) · 형식: [변경 기록 규칙](../manual/change-workflow.md#records)

2026-10-28 계정별 공유·댓글의 주관 기록은 [PLAT-20261028-04](PLAT-20261028-04-account-isolation.md)다. 기존 KHTP owner/수정/재분석/PDF POST는 보존하고 목록·image/data만 유효 공유 읽기를 확장했다. 공통 저장본 화면에서 무저장 PDF·개인 메모·수신자별 대화를 제공한다. 모델/관찰/팩·기존 기록 소유권은 변경하지 않는다.

## 기록

이 대장은 2026-10-28부터의 신규 변경을 기록한다. 과거 작업·commit·검증 결과를 추측해 이관하지 않는다. 아래는 대장 최초 작성 당시 기록이며 이후 패치는 위 날짜별 항목에 누적한다.

공통 문서 체계 추가는 [PLAT-20261028-01](platform.md#plat-20261028-01)에 연결한다. 이번 정비는 K-HTP 그림·관찰·모델·저장본을 변경하지 않았다. 다음 K-HTP 패치부터 `KHTP-YYYYMMDD-NN`과 해당 `KHTP-M*` 기능 ID로 기록한다.

공통 회원가입 추가는 [PLAT-20261028-02](platform.md#plat-20261028-02)가 소유한다. K-HTP 도메인 코드·소유권·관찰·모델은 변경하지 않았다. 허용된 신규 계정의 가입/로그인 이후 K-HTP 목록 이동을 격리 브라우저에서 확인했고 기존 소유권 테스트도 전체 회귀 검증에 포함했다.

후속 공개 가입 선택과 기본값 반영은 [PLAT-20261028-03](platform.md#plat-20261028-03)에 연결한다. 기존 K-HTP 소유권은 유지하며 공개 가입/로그인 이후 K-HTP 목록 이동도 최신 브라우저 회귀에 포함했다.
