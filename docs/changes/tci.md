# TCI 수정·패치 대장

## PLAT-20261029-03 · 댓글 복구·대상자 검색

상태: 구현·자체 검증·독립 검수 통과, 운영 미적용. 검사 댓글 신규/수정 실패 시 제출값 복구와 공통 대상자 검색 Enter의 부모 폼 제출 방지를 적용했다. 점수/본문/계산·저장 소유권은 유지한다. 전체 326건, 브라우저 11개 흐름(TCI 개인/공유 댓글 실패·재시도 및 검색/명시 저장 포함), 독립 19건 통과. 공통 변경·증거·한계·운영 상태는 [주관 대장](platform.md#plat-20261029-03)을 따른다.

<a id="plat-20261029-review-03"></a>
## 2026-10-29 추가 검수

R2~R5 보완은 유지된다. 추가로 검사 메모·댓글 신규/수정의 DB 조회 장애 시 입력 복구가 없는 R7(P2)을 TCI 실제 HTTP로 재현했다. 이번 검수에서 제품 코드는 수정하지 않았다. 공통·K-HTP 포함 전체 발견 3건과 집중 43건 검증·미실행 범위는 [추가 검수 대장](platform.md#plat-20261029-review-03)을 따른다.

<a id="plat-20261029-02"></a>
## PLAT-20261029-02 · TCI 대상자 변경과 일정 연결

상태: 구현·자체 검증·독립 재검수 통과, 운영 미적용. 대상자 코드 변경 시 같은 소유자의 불일치 일정에 한해 검사 연결을 같은 저장 트랜잭션에서 해제하고, 약속 대상자·시간·내용·공유·댓글은 유지한다. 개정을 갱신해 오래된 일정 편집의 덮어쓰기를 차단하며 저장 안내에 해제 건수를 표시한다. 전용 4건을 포함해 전체 311건 및 격리 PostgreSQL 보완 25건을 통과했다. 실제 대상자 검색·변경 안내, 기존 작성/병합/공유 흐름과 TCI PDF 4쪽도 재확인했다. 독립 검수 29건 통과·추가 필수 수정 0건이다. 계약과 전체 검증/운영·복구 상태는 [공통 변경 기록](platform.md#plat-20261029-02)을 따른다. 새 스키마나 검사 계산·본문 변경은 없다.

<a id="plat-20261029-01"></a>
## PLAT-20261029-01 · 2026-10-29 · TCI 연동

상태: 구현·격리 검증·독립 리뷰 통과, 운영 미적용. 주관: 공통 기반. [계약 원본](../ssot/08-people-scheduler.md). 대상자 코드·검색·수동 병합, 검사/일정 연결, 일정 공유·댓글, 관리/기능 스위치와 TCI 저장 보호를 추가했다. 기존 검사 계산·본문·그림·PDF·소유권은 보존한다. 병합 시 충돌 방지용 시각/개정만 갱신한다.

영향: UI·DB·API·권한 변경 있음, 원본 자료·PDF 생성 형식 변경 없음. 새 의존성 없음. 새 레이아웃 Flexbox, 추가 아이콘 없음. 전체 회귀 286건과 독립 집중 50건, 격리 DB/브라우저/PDF 검증을 통과했다. Git 커밋/푸시, 운영 이관/배포 미실행. 복구는 서비스 중지 후 코드와 배포 전 DB 백업의 함께 복원이며 자동 downgrade는 없다.

검증 상세·R1 보완·증거·제한은 [공통 변경 대장](platform.md#plat-20261029-01)을 따른다.

관리: TCI 익스큐트 / 오케스트라 · 계약: [TCI SSOT](../ssot/05-tci.md) · 형식: [변경 기록 규칙](../manual/change-workflow.md#records)

2026-10-28 계정 분리·공유·댓글의 주관 기록은 [PLAT-20261028-04](PLAT-20261028-04-account-isolation.md)다. TCI owner/미귀속격리·모든 원본 수정/PDF shortcut 소유 검사·소유/공유 목록/이력 필터, 저장본 읽기/무저장 PDF를 연결하고 일정은 통합 대시보드로 이동했다. 기존 점수·본문·조건·직접편집 보존 계약은 유지한다. 사용자가 기존 TCI/일정 모두 sura 소유로 확인했다. 이전 공동 열람 설명은 당시 이력이며 현재 [계정·공유 SSOT](../ssot/07-account-sharing.md)를 따른다.

## 기록

이 대장은 2026-10-28부터의 신규 변경을 기록한다. 과거 작업·commit·검증 결과를 추측해 이관하지 않는다. 아래는 대장 최초 작성 당시 기록이며 이후 패치는 위 날짜별 항목에 누적한다.

공통 문서 체계 추가는 [PLAT-20261028-01](platform.md#plat-20261028-01)에 연결한다. 이번 정비는 TCI 동작·자료·저장본을 변경하지 않았다. 다음 TCI 패치부터 `TCI-YYYYMMDD-NN`과 해당 `TCI-M*` 기능 ID로 기록한다.

공통 회원가입 최초 구현은 [PLAT-20261028-02](platform.md#plat-20261028-02), 사용자 공개 가입 선택 반영은 [PLAT-20261028-03](platform.md#plat-20261028-03)이 소유한다. 당시 무설정 기본값을 공개 가입으로 바꿨으며 신규 계정의 기존 TCI 공동 열람/수정은 이후 계정 분리 계약으로 대체됐다. 현재는 본인 또는 명시 공유 자료만 접근한다. 이 가입 패치 당시에는 TCI 도메인 코드를 변경하지 않았고 가입/로그인 이후 대시보드·리뷰·최종 보고서 이동과 격리 기존 보고서 보존을 확인했다.
