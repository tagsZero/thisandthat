## 로그인과 TCI 대시보드

계정 생성 명령 또는 웹 회원가입으로 만든 계정으로 로그인하고 통합 대시보드에서 TCI를 선택한다. 2026-10-28 요청으로 회원가입을 추가했다. 아이디·비밀번호·확인, 설정 시 초대 코드를 검증하며 기존 users에 해시로 새 계정만 저장한 뒤 로그인 화면으로 이동한다. 상세 계약은 [공통 PLAT-05](04-platform.md#registration)를 따른다. 로그인 상태에서 사이트에 재접속하면 통합 대시보드를 연다. 이후 계정 분리 지시로 본인/공유 검사만 조회하며 조직별 권한 관리는 포함하지 않는다.

TCI 대시보드 상단에는 새 점수 입력을 두고 본문에는 접근 가능한 최근 검사 목록을 배치한다. 오늘·이번 주 개인 일정과 공유받은 TCI/KHTP 통합 목록은 통합 대시보드에 둔다.

| 기능 | 동작 |
|---|---|
| 새 점수 입력 | 빈 검사결과 입력 양식으로 이동 |
| 최근 검사 목록 | 최근 수정 순으로 이름 또는 관리번호, 검사일, 저장된 기질·성격유형, 수정일 표시 |
| 검색 | 이름·관리번호·검사일로 기존 검사 기록 찾기 |
| 빠른 리뷰 | 저장된 점수·분류 기준·유형·선택한 해석 일부를 펼쳐 확인 |
| 이어 작성 | 해당 검사 기록의 입력·선택·편집 내용을 불러와 작성 |
| 일정 | 오늘·이번 주 조회, 일정 등록·수정·삭제 |

빠른 리뷰에서 전체 보고서를 열 수 있다. 입력이 덜 된 기록은 미입력 상태를 그대로 표시하며 유형을 추정하지 않는다. 빠른 리뷰는 저장된 내용을 사용하고 최신 자료로 문장을 교체하지 않는다. 같은 사람이 다른 날 받은 검사는 별도 검사 기록으로 저장한다.

일정은 날짜·시간·제목·메모와 선택적인 검사 기록 연결로 구성한다. 한국 시간을 기준으로 표시하며 일정 등록을 검사결과 입력의 필수 절차로 만들지 않는다. 외부 캘린더 연동·알림 발송·예약 접수는 포함하지 않는다.

## 검사결과 입력

초기 입력 양식은 사용자가 제공한 TCI-RS 결과지를 기준으로 한다. 검사 실시와 문항 응답 기능은 만들지 않는다.

| 영역 | 항목 |
|---|---|
| 대상 정보 | 이름 또는 관리번호, 검사일, 검사판 |
| 기질 | NS 자극추구, HA 위험회피, RD 사회적 민감성, PS 인내력 |
| 성격 | SD 자율성, CO 연대감, ST 자기초월 |
| 주척도별 수치 | 원점수, T점수, 백분위 |
| 추가 입력 | 결과지에 있는 하위척도, 선택적인 SC 자율성 및 연대감 수치 |

입력은 수동으로 시작한다. 원점수에서 T점수나 백분위를 산출하지 않는다. SC의 T점수와 백분위를 다른 수치의 합으로 만들지 않는다.

임시 저장은 일부 입력만으로 가능하다. 기질은 NS·HA·RD, 성격은 SD·CO·ST의 T점수가 있으면 각각 유형과 상세 설명을 표시한다. PS는 유형 코드 완성 조건에 넣지 않는다. PDF는 기존처럼7개 주척도 T점수를 검증한다. 원점수·백분위·하위척도가 없으면 미입력으로 유지하고 해당 수치가 필요한 표시·해석만 생략한다. 백분위 위치를 추정하지 않는다.

원점수는 0 이상의 정수, 백분위는 0 이상 100 이하의 수, T점수는 유효한 수치로 받는다. T점수에 백분위의 0~100 제한을 복사하지 않는다. 하위척도 원점수는 확인된 해당 검사판의 입력 형식에 맞춘다. 빈칸은 0으로 바꾸지 않는다.

## 분류 기준 선택

주 분류에는 T점수를 사용한다. 백분위는 결과지의 수치 그대로 프로파일 위치에 사용한다.

| 설정 | 낮음 L | 중간 M | 높음 H |
|---|---|---|---|
| 기본 T56 | T ≤ 45 | 45 < T < 56 | T ≥ 56 |
| 비교 T55 | T ≤ 45 | 45 < T < 55 | T ≥ 55 |
| 사용자 지정 | T ≤ 낮음 종료값 | 두 경계 사이 | T ≥ 높음 시작값 |

기본값은 T56이다. T55의 낮음 종료값 45는 이번 제품의 비교용 설정이다. 이 표의 설정을 모든 전문가의 공통 기준이나 공식 규준이라고 표시하지 않는다. T50 등 다른 기준은 사용자 지정으로 설정한다.

높음 시작값은 낮음 종료값보다 커야 한다. 두 경계 사이에서 중간을 계산하므로 소수점 구간에도 빈틈이 없다. 경계가 겹치면 해당 설정만 적용하지 않고 입력 위치에 설명한다.

기본은 입력한 T점수를 그대로 분류한다. 상세 설정에서 소수 첫째 자리 또는 정수 반올림을 선택할 수 있다. 반올림은 십진수의 사사오입으로 처리하며, 분류에 사용하는 값만 바꾼다. 입력 점수를 덮어쓰지 않는다. 반올림으로 결과가 바뀌면 입력값과 분류 적용값을 함께 확인할 수 있게 한다.

기본 경계는 전체 주척도에 공통 적용한다. 필요한 해석자는 상세 설정에서 특정 척도만 별도 경계로 바꿀 수 있다. 자료에 저장된 설명이나 조건이 이 설정을 몰래 변경해서는 안 된다.

기질유형은 NS·HA·RD 순서, 성격유형은 SD·CO·ST 순서의 H/M/L 세 글자로 만든다. PS는 개별 프로파일과 해석에 사용한다. 분류 기준이나 점수를 바꾸면 분류·유형·해석 후보를 다시 계산한다.

## 54유형 자료와 통합 설명

사용자가 제공한 자료의 통합54개는 **제공 자료 기반 해석 초안**으로 사용한다. 선택한 T기준의 기질/성격 코드와 맞는 본문을 각각 한 번 자동 포함한다. 검사판·성인 적용 근거 미확인과 unknown/reference 원값은 출처 사본에 보존하고, 그 사실만으로 이 통합 본문을 차단하지 않는다. 공식 성인용 검증 완료나 표준 규준으로 표시하지 않는다. 이 사용 규칙은 승인된 기존 통합54개에 한정하며 모든 참고자료를 자동 포함하도록 넓히지 않는다. 실제 점수의 필수 조건·명시적 연령/검사군 제한·비활성화·손상된 조건·다른 유형·비출력 비교는 계속 구분한다.

네 자료를 기질27·성격27유형별로 대조해 같은 내용을 통합 설명으로 정리하고 다른 내용은 차이와 출처를 연결한다. 자료별 전사를 나열하거나 사용자가 공통 문장을 직접 골라 합치게 하지 않는다. 기존 원문·관리·수록 현황을 사용하며 새 문서는 만들지 않는다.

현재 기질·성격 코드의 통합 설명을 새 보고서의 기본 본문으로 자동 구성한다. B·C·D가 같고 A가 다르면 기본은 공통 설명 하나다. A가 다른 점을 설명하고 [자료 A 해석 추가]를 제공한다. 누르지 않으면 기본만, 누르면 기본+A가 출력된다. 같은 문장 세 벌을 출력하지 않는다.

원문에 있는 세부·하위척도 설명도 같은 본문에서 읽는다. 필요한 개인 점수가 없으면 개인 세부 결과를 만들지 않는다. 기질/성격 코드·원본T/적용T/백분위 조건과 명시적 검사군 제한을 혼용하지 않는다. 검사판 정보가 미확인인 것과 개인 조건 미충족을 구별한다.

54유형의 실제 통합 본문·출처·확인 상태와 미수록을 구별한다. 제목·전사만 나열한 상태는 통합 본문이 아니지만 reference 메타데이터는 승인된 통합54개의 자동 사용을 막지 않는다. 기본 전체를 읽게 하고 출처·원문·긴 조건은 필요할 때 펼친다. 파일·전문가·척도·목차 선택은 선행 작업이 아니다.

## 다른 해석 추가와 본문 수정

통합 설명은 기본 포함이며 별도 적용·일괄 반영 버튼이나 단일/다중 선택 모드를 요구하지 않는다. 다른 해석에만 추가 버튼을 둔다. 추가·취소는 그 문장만 변경하며 통합 본문·다른 추가문·직접 의견은 유지한다. 중복 추가하지 않는다. 본문 안에서 직접 수정한다.

좌측/상단 배치는 같은 작성 상태를 사용한다. 전환만으로 조회·분류·저장하지 않고 내용·편집 위치를 유지한다. 기준을 직접 바꾸면 두 유형과 수정하지 않은 자동 통합 설명을 함께 갱신한다. 직접 편집·추가한 내용은 유지하며 유형 차이를 표시한다.

저장한 보고서는 저장 본문을 읽는다. 자료 업데이트·단순 열기로 새 설명을 덮어쓰거나 사용자가 지운 기본 본문을 되살리지 않는다. 자동 초안은 조회 중 DB에 쓰지 않고 명시적 저장·PDF에서 현재 내용을 저장한다. 기존 body/v1/v2는 읽을 수 있어야 한다.

## 보고서 구성

추가 영역의 포함 여부는 보고서에서 미리보고 명시적으로 저장한다. 제외해도 점수·선택문·의견은 유지한다. 기존 해석 편집기를 다시 저장해도 이 설정을 보존한다. 보고서 GET과 표시 미리보기는 저장된 보고서·수정 시각을 변경하지 않는다.

| 기본 영역 | 내용 |
|---|---|
| 기질 프로파일 | NS·HA·RD·PS의 백분위 막대, H/M/L 마커, 짧은 척도 설명 |
| 기질 해석 | 기질유형, 타고난 특성, 대인관계 특성, 기질 수용하기 |
| 성격 프로파일 | SD·CO·ST의 백분위 막대, H/M/L 마커, 짧은 척도 설명 |
| 성격 해석 | 성격유형, 삶을 바라보는 방식, 성격 가꾸기 |
| 선택 추가 영역 | 하위척도 상세, 기질·성격 연계해석, 전문가 종합 소견 |

사용자가 제공한 이미지 1·2는 기질 결과 한 묶음, 이미지 3·4는 성격 결과 한 묶음으로 사용한다. 보고서에는 두 묶음을 연속 배치한다. 점수에 따라 마커 위치·유형·설명이 바뀌고, 통합 설명은 기본 포함하고 추가한 다른 해석만 더 들어간다. 이미지의 특정 대상자 문장을 공통 보고서 문장으로 복사하지 않는다.

보고서에는 막대 위치가 백분위이고 H/M/L은 선택한 T점수 기준이라는 설명을 둔다. 기존 이미지의 백분위 30·70 설명을 현재 T분류의 설명으로 그대로 붙이지 않는다.

하단에는 실제 낮음·높음 경계와 반올림 방식을 표시하고, 척도별 별도 경계가 있으면 해당 척도를 덧붙인다. 이전 기준이나 다른 검사판의 문장을 유지한 경우 최종 보고서에도 참고 표시를 남긴다.

PDF 표시 설정을 저장한 뒤에도 열린 웹 본문은 마지막으로 연 미리보기일 수 있다. PDF 성공과 저장 후 생성 실패에는 이 차이를 안내하고, 저장된 표시 설정은 보고서를 다시 열어 확인한다. 본문을 강제로 갱신해 생성 중 추가 편집을 덮어쓰지 않는다.

## 현재 작업 저장과 PDF

현재 점수·선택 기준·선택 해석·편집한 본문·의견을 한 보고서로 저장하고 다시 열 수 있다. 수정 저장은 현재 내용을 갱신한다. TCI 대시보드의 목록에서 이름 또는 관리번호와 검사일로 간단히 찾는다.

자동 통합 본문과 사용자가 추가·편집한 내용은 현재 보고서 본문으로 함께 저장한다. 이후 소스 문장을 수정해도 이미 작성한 보고서 본문이 자동 변경되지 않는다. 새 후보를 선택할 때는 최신 소스 내용을 사용한다. 별도 과거 버전 보관 기능은 만들지 않는다.

PDF 다운로드는 현재 편집 내용을 먼저 저장하고 그 내용으로 출력한다. 자료 비교용 조작부는 출력하지 않는다. A4 세로를 기본으로 하고, 내용에 따라 페이지를 나눈다. PDF4페이지나27쪽을 강제하지 않으며 편지·MBTI를 추가하지 않는다.

편집 화면의 현재 문장·의견·순서·기준·포함 설정, 보고서 표시 미리보기의 현재 포함 설정을 명시적으로 저장한다. 7개 주척도 T·본문 구조·기준 검증 실패 시 이 요청의 저장과 PDF를 모두 보류한다. 커밋 후 PDF 실패는 저장 완료로 구별하며 현재 저장본의 PDF만 읽기 전용으로 재시도한다. 재시도는 수정 시각을 변경하지 않는다. 요청 후 추가 편집은 미저장으로 유지한다.

## 해석자료 추가와 수정

TCI의 자료 관리에서 소스 추가, 소스 정보 수정, 해석문 추가·수정, 적용 조건 지정, 사용 중지를 제공한다. 자료와 해석은 DB 데이터로 관리하여 새 해석 등록 때 프로그램 코드를 고치지 않게 한다.

첫 버전은 정리된 텍스트를 붙여 넣거나 입력하는 방식이다. 원본 파일명과 페이지·슬라이드·절 위치를 함께 적을 수 있다. PDF·PPT·HWPX 자동 변환이나 파일 업로드만으로 전체 해석을 완성하는 기능은 포함하지 않는다. 기질27·성격27 상세 본문 수록은 현재 핵심 제작 범위이며 다른 이론·하위척도·연계 전수 수록과 분리한다.

자료를 저장하면 이후 조회·후보 새로고침부터 반영한다. 사용 중지한 항목은 새 추천에서 제외하고, 이미 작성한 보고서 문장은 유지한다. 업데이트 때마다 프로그램 배포를 요구하지 않는다.

## 첫 제품의 범위

기본 로그인, 통합 대시보드, TCI 대시보드의 빠른 리뷰·일정, 보고서 작성 세 단계, 현재 보고서 저장·열기, PDF, 간단한 자료 관리를 만든다. 사용자별 자료 접근 권한·보안 강화·백업·복구·보고서 버전 이력·다른 도구·외부 AI 연동·검사 문항 응답·OCR은 이번 범위에 넣지 않는다.

## 기능 완료 기준

54유형의 실제 통합 설명이 준비돼야 한다. 추가 클릭 없이 두 유형 본문으로 저장·PDF를 끝내고, A를 추가하면 통합 설명+A만 출력되어야 한다. HHL/MHM 등 초기 예시 외 유형도 확인한다. 전사 나열·제목·기본 설명 적용 버튼만으로 완료하지 않는다.

로그인 후 통합 대시보드에서 TCI 대시보드로 이동하고, 새 점수 입력·기존 결과 빠른 리뷰·이어 작성·일정 관리를 선택할 수 있어야 한다.
