K-HTP의 자동 계산·모델 후보·사용자 관찰 분류는 내부 설계표에만 사용한다. 화면에 모드·모델·분류 선택을 추가하지 않는다. 기존8그룹에서 관찰값과 근거를 보고 필요한 부분을 수정하며, 불확실한 항목만 확인 필요로 표시한다. 행별 승인 클릭이나 모든 미해결 항목 해소를 PDF의 필수 조건으로 만들지 않는다. PDF는 자동/사용자 작성과 미확인 이유를 유지하며 내려받기를 정확성 확인으로 취급하지 않는다.

항목별 표시와 실패 예시는 [자동 관찰 범위표](../references/khtp-automation-boundary.md)를 따른다. 가지는 ‘가지로 보이는 영역 — 범위 확인 필요’처럼 단위 보류를 표현하고, 후보 영역을 정확한 개수로 표시하지 않는다. 미실행·미탐지·사람이 보아도 불분명함을 기존 상태로 구별하며 A/B/C·confidence·모델 이름을 사용자 설정으로 노출하지 않는다. 이 문구를 화면 계약으로 사용하며 실제 UI/PDF 검증 상태는 이 문서 첫 문단과 진행 현황을 따른다.

K-HTP 결과 표의 [한국어 견본](../references/khtp-observation-draft.md)은 8개 그룹으로 묶는다. 내부의24개 세부 정의를24개의 필수 입력이나 승인 절차로 늘리지 않는다. 기본 화면에는 이름·관찰값을 표시하며 세부 출처·코드는 접힌 영역에 둔다. 확인할 부분은 기존 미해결 관찰의 모아보기이며 새 입력이나 승인 절차가 아니다. 원리적으로 사진에서 알 수 없는 항목은 필수 경고로 쌓지 않는다. 이는 2026-10-24 문서 초안에서 정한 구조이며, 현재 기능 구현과 실제 사용자 사용성 검증은 구분한다.

2026-10-28 공통 화면 원칙: 신규·변경 배치는 **Flexbox로 구현**한다. 작업 영역의 좌우 배치·모바일 세로 전환·버튼 줄·카드 정렬도 이에 따른다. Flexbox로 구현하기 어려울 때만 Grid를 예외 사용하고 selector·어려운 이유·Flexbox 검토 결과·영향과 검증 결과를 변경 기록에 남긴다. 실제 관찰표·점수표는 의미에 맞는 HTML table을 사용한다. UI 아이콘은 Tabler 제공 아이콘만 사용하며 공식 SVG·출처를 기존 Jinja 매크로로 관리한다. 스타일별 소유권은 [공통 UI 규칙](../manual/ui-rules.md), 기능별 소스 진입은 [인덱스](../manual-index.md#routing)를 따른다. 기존 TCI 화면 전체를 이 원칙만을 이유로 재작성하지 않는다. 이번 정비는 화면·CSS·아이콘 코드를 변경하지 않았다.

두 번째 프로그램의 [K-HTP 화면 설계](../tasks/KHTP-program-design.md)는 공통 메뉴에서 간단한 검사 목록을 열고 새 검사 또는 기존 기록을 기존 작업 화면으로 연결한다. 편집 화면 안에서 그림 등록·자동 관찰표·필요한 수정·관련 자료 펼침·PDF를 제공한다. 양식 선택·자료 관리·미리보기 페이지는 만들지 않는다. 공개 자료에 기반한 자체 기본 양식 하나를 사용한다. 최신 구현 상태는 이 문서 첫 문단을 따르며 이하 TCI 요구와 상태는 유지한다.

## 화면 참고 기준

대상자·검사 기록 목록, 빠른 리뷰와 보고서 작업은 Q-global, NovoPsych, PsyPack의 공개 화면과 공식 안내를 참고한다. 일정 배치는 Cliniko의 공개 안내를 추가로 참고한다. 관찰 내용과 적용 판단은 [작업 화면 참고 조사](../references/ui-reference-review.md)에 정리한다. 이들 서비스의 로그인 내부 기능을 직접 사용한 것으로 간주하지 않는다.

사용자가 제공한 네 장의 스크린샷은 최종 보고서의 형태 기준이다. 작업 화면은 입력·비교·선택에 맞게 구성하고, 최종 보고서의 장식을 모든 작업 화면에 반복하지 않는다. 프로파일과 해석 영역의 두 배치는 이 프로젝트 요구에 맞춘 자체 구성이다.

## 공통 탐색

TCI 상단에는 TCI 대시보드로 돌아가는 링크를 두고, 보고서 작성 중에는 점수·T기준 입력, 자동 보고서 확인, 저장·PDF의 단계 표시를 둔다. 이전 단계로 돌아가도 현재 입력·선택·편집 내용은 유지한다. 기본 화면에는 현재 단계에서 필요한 조작만 둔다.

현재 작업 저장은 단계마다 사용할 수 있다. 저장한 보고서 열기와 검색은 TCI 대시보드의 최근 검사 목록에서 제공한다.

현재 대상과 단계를 상단에서 확인할 수 있게 하고 단계마다 다음 주요 행동 하나를 강조한다. 기능을 나열하는 큰 사이드바는 두지 않는다.

## 로그인과 통합 대시보드

로그인은 가운데 간단한 아이디·비밀번호 입력란과 로그인 버튼으로 구성한다. 로그인 실패는 입력란 근처에 표시한다. 성공하면 통합 대시보드를 연다. 버튼 아래 회원가입 링크로 `/register`를 연다. 가입 화면은 전용 Flexbox 배치로 PC의 소개/폼 좌우 구성과 모바일 세로 구성을 제공하며 아이디·비밀번호·확인, 설정 시 초대 코드를 입력한다. 각 오류는 해당 필드와 연결하고 아이디는 유지하되 비밀번호는 다시 표시하지 않는다. 비밀번호 표시/숨김, 가입하기, 로그인으로 돌아가기를 제공한다. 가입 성공은 로그인 화면에서 안내한다. 처리 계약은 [PLAT-05](04-platform.md#registration)를 따른다.

통합 대시보드에는 TCI/KHTP 카드·개인 일정·공유받은 검사와 로그아웃을 둔다. 카드로 해당 프로그램의 계정별 목록을 연다. 로그인 상태에서 사이트에 재접속하면 통합 대시보드를 표시한다.

## TCI 대시보드

상단에는 TCI 제목과 새 점수 입력 버튼을 둔다. 본문은 계정별 소유/공유 검사 목록을 넓게 표시하고 일정은 통합 대시보드에서 관리한다. 좁은 화면에서는 검사 정보와 조작이 세로로 줄바꿈한다.

| 영역 | 구성 |
|---|---|
| 상단 | 통합 대시보드로 이동, TCI 제목, 자료 관리, 새 점수 입력 |
| 최근 검사 목록 | 이름·관리번호·검사일 검색, 최근 수정 순 검사 기록, 기존 데이터에서 계산한 입력·해석 작성 정도 |
| 목록의 한 행 | 이름 또는 관리번호, 검사일, 기질·성격유형, 최근 수정일, 빠른 리뷰, 이어 작성 |
| 빠른 리뷰 펼침 | 저장된 점수 요약, 적용 기준, 유형, 선택한 해석 일부, 전체 보고서 열기 |
| 일정 | 오늘·이번 주 전환, 시간·제목 목록, 일정 추가 |

빠른 리뷰는 선택한 행 아래에서 펼쳐 다른 검사 기록으로 쉽게 옮겨갈 수 있게 한다. 새 해석을 생성하지 않고 저장된 보고서를 보여준다. 같은 이름의 별도 검사 기록은 검사일과 관리번호로 구별한다.

개인 일정 추가·수정은 통합 대시보드의 작은 입력 패널로 제공한다. 날짜·시간·제목·메모와 접근 가능한 TCI를 연결한다. 연결 검사 권한이 회수되면 검사 메타/링크는 숨긴다. 일정은 소유자만 조회/수정/삭제하며 오늘·이번 주 목록으로 구성한다.

기록이 없으면 “아직 저장한 검사 결과가 없습니다”와 새 점수 입력을 표시한다. 일정이 없으면 “등록된 일정이 없습니다”와 일정 추가를 표시한다. 데이터가 없는 영역을 예시 대상자나 가짜 일정으로 채우지 않는다.

## 점수 입력 화면

상단에는 이름 또는 관리번호와 검사일을 둔다. 검사판은 초기 TCI-RS 양식으로 표시한다.

점수표는 기질 4행, 성격 3행으로 구분하고 열은 척도, 원점수, T점수, 백분위 순서로 둔다. 같은 행에서 현재 분류를 확인한다. 척도에는 한국어 이름과 약어를 함께 쓴다. 표의 입력 칸을 키보드로 순서대로 이동할 수 있게 한다.

하위척도와 SC는 추가 점수 입력을 펼쳐 작성한다. T점수·백분위를 원점수로부터 자동 채워 넣지 않는다. 입력 오류는 해당 칸 옆에서 짧게 설명한다. 임시 저장과 해석 보기는 분리하여 일부 점수만으로도 작업을 저장할 수 있게 한다.

## 자동 해석 보고서 화면

기본 본문은 ‘제공 자료 기반 통합 설명’으로 표시한다. 승인된54개의 unknown/reference만으로 본문을 숨기거나 전체를 ‘추가 참고/조건 불충족’으로 표시하지 않는다. 검사판 확인 상태·출처는 기존 근거 영역에 간결히 남기고 실제 유형/점수 조건 차이와 구별한다. 공식 성인용 해석으로 검증됐다고 표시하지 않는다. 다른 해석의 추가/취소와 두 배치는 유지하고 확인 토글·승인 절차·새 화면은 만들지 않는다.

첫 화면은 현재 기질·성격 코드와 통합 설명이 이미 들어간 본문이다. 기질 설명 다음 성격 설명을 연속해서 읽는다. 기본 설명 적용 버튼·후보 검색·하나/여러 개 선택 모드·선택 내용 탭은 두지 않는다.

좌측 프로파일/우측 본문과 상단 프로파일/하단 본문을 토글로 전환한다. 좁은 화면은 한 열이다. T56/T55/사용자 지정과 두 유형은 상단에 간단히 표시하고 상세 경계·반올림·근거는 펼친다. 배치 전환은 같은 본문과 편집 위치를 유지하며 저장·조회·재분류하지 않는다.

다른 해석은 본문 아래에 차이와 출처를 설명하고 [자료 A 해석 추가] 버튼을 둔다. 클릭하면 해당 추가문이 보고서에 들어가고 버튼은 추가됨·취소 상태가 된다. 누르지 않은 다른 해석은 출력하지 않는다. 통합 본문을 다시 선택할 필요는 없다. 자료에 있는 세부·하위척도 설명도 해당 본문에서 읽는다.

```text
[T기준] [기질 HHH · 성격 MHM] [좌측/상단 배치]
기질 HHH 통합 설명 — 기본 보고서에 포함
  다른 해석: 자료 A는 ○○가 다릅니다. [자료 A 해석 추가]
성격 MHM 통합 설명 — 기본 보고서에 포함
  다른 해석: 자료 B는 △△가 다릅니다. [자료 B 해석 추가]
[저장] [보고서·PDF]
```

본문은 직접 수정할 수 있다. 기준을 바꾸면 수정하지 않은 자동 본문을 갱신하고 직접 편집·추가문은 유지해 차이를 표시한다. 기존 저장본 열기나 자료 갱신만으로 본문을 바꾸지 않는다. 데스크톱 첫 화면에 두 코드와 본문 시작이 보이고 모바일에서 겹침·작업줄 가림이 없어야 한다.

## 보고서 완성 화면

사용자가 첨부한 결과 이미지의 구성과 읽기 흐름을 따른다.

본문은 가운데 한 열로 배치하고 상단에 해석 편집으로 돌아가기, 저장 후 PDF 다운로드와 접힌 추가 영역 표시 설정을 둔다. 본문 수정은 해당 선택문으로 편집 복귀해 수행하고 저장 후 보고서 보기로 돌아온다. 표시 미리보기는 미저장이고 표시 설정 저장 또는 PDF 다운로드가 현재 포함 여부를 저장한다. 저장 후 PDF 실패는 저장 완료로 표시하고 현재 저장본 PDF만 재시도하는 링크를 제공한다. 비교 화면의 후보 목록과 자료 관리 조작은 보고서 읽기 영역에서 제외한다.

| 순서 | 영역 | 표현 |
|---|---|---|
| 1 | 대상 정보 | 이름 또는 관리번호, 검사일, 검사판 |
| 2 | 기질 프로파일 | NS·HA·RD·PS의 색상 막대와 원형 마커 |
| 3 | 기질유형과 해석 | NS·HA·RD의 유형 코드, 타고난 특성, 대인관계, 기질 수용하기 |
| 4 | 성격 프로파일 | SD·CO·ST의 색상 막대와 원형 마커 |
| 5 | 성격유형과 해석 | SD·CO·ST의 유형 코드, 삶을 바라보는 방식, 성격 가꾸기 |
| 6 | 선택 추가 영역 | 하위척도 상세, 기질·성격 연계해석, 전문가 종합 소견 |

기질과 성격은 서로 다른 묶음으로 연속 배치한다. 이미지 1·2를 기질 묶음, 3·4를 성격 묶음으로 해석한다.

프로파일은 밝은 배경, 남색 계열 제목, 충분한 여백, 얇은 구분선과 해석 상자로 구성한다. 막대는 낮음에서 높음 방향으로 색상이 이어지고, 원형 마커 안에 H/M/L을 넣는다. 마커와 함께 백분위 수치를 문자로 표시한다. H는 주황, M은 초록, L은 파랑 계열로 구분한다.

막대의 위치는 백분위 0~100의 실제 값으로 정한다. 유형 마커의 문자는 선택한 T분류 결과로 정한다. 백분위가 없으면 위치를 임의로 그리지 않고 미입력으로 표시한다. 원점수와 T점수는 점수 자세히 보기에서 확인한다. 보고서 아래에 막대 위치와 분류 기준의 차이를 짧게 설명한다.

하단의 기준 설명에는 실제 적용 경계와 반올림도 표시한다. 예를 들어 기본값은 “T점수 분류: 낮음 45 이하 · 높음 56 이상 · 반올림 없음”으로 쓴다. 척도별 예외는 해당 척도만 추가한다. 이전 기준이나 다른 검사판의 선택문에는 짧은 참고 표시를 붙여 PDF에도 유지한다.

해석 제목과 문장은 참조의 구조를 따르되 현재 선택한 자료와 점수에 따라 채운다. 사용자가 문장을 직접 수정하고 추가 영역의 포함 여부를 선택할 수 있게 한다. 통합 설명은 기본 포함하며 추가하지 않은 다른 해석이나 차이 비교 목록은 최종 본문에 넣지 않는다.

저장과 PDF 다운로드를 눈에 띄는 위치에 둔다. PDF 다운로드 한 번으로 현재 편집 내용을 저장한 뒤 같은 내용으로 출력한다. PDF에는 편집 버튼·토글·원문 펼치기·후보 목록을 제거한다. A4 세로로 출력하며 긴 해석을 잘라 버리거나 글씨를 과도하게 줄이지 않고 다음 페이지로 이어 간다.27쪽을 강제하거나 편지·MBTI를 추가하지 않는다.

PDF 표시 설정을 저장한 뒤에도 열린 웹 본문은 마지막으로 연 미리보기일 수 있다. PDF 성공과 저장 후 생성 실패에는 이 차이를 안내하고, 저장된 표시 설정은 보고서를 다시 열어 확인한다. 본문을 강제로 갱신해 생성 중 추가 편집을 덮어쓰지 않는다.

## 자료 관리 화면

한 화면에서 소스 목록을 선택하고 관련 해석을 추가·수정한다. 소스에는 제목, 전문가명 또는 저자명, 관점 설명, 원본 파일명, 사용 여부를 둔다. 확인되지 않은 전문가명을 임의로 채우지 않는다.

해석 항목에는 보고서 항목, 관점, 원문, 보고서용 설명, 관련 척도·유형, 적용 조건, 원문 위치, 선택적인 유사 묶음·상충 표시를 둔다. 기본 입력은 제목·설명·연결 항목이고 상세 조건은 펼친다.

상세 수치 조건에는 비교할 점수 종류, 하한·상한, 경계 포함 여부를 둔다. 원본 T점수와 반올림 후 분류 적용값은 선택지 이름으로 구별한다.

자료 저장 뒤 후보에 반영된다는 안내만 제공한다. 사용 중지는 새 추천에서 제외하는 동작이다. 별도 승인 단계나 자료 업데이트 이력 화면은 만들지 않는다.

## 화면 완료 기준

- 사이트 접속 → 로그인 → 통합 대시보드 → TCI 대시보드 순서로 이동한다.
- TCI 대시보드에서 새 입력·기존 결과 빠른 리뷰·이어 작성·일정 관리를 선택할 수 있다.
- 입력 후 현재 두 유형의 실제 상세 본문이 기본 화면에 연속 표시되고 파일·척도·네 탭 선택을 먼저 요구하지 않는다.
- 근거·상세 설정은 펼치고 통합 설명 자동 포함·문단 안 선택/편집·제외를 제공한다.
- 같은 점수로 기준을 바꾸면 유형과 후보가 갱신되고 입력값은 유지된다.
- 좌측·상단 배치를 전환해도 기준·선택·편집문·검토 위치와 저장 상태가 유지되며 전환만으로 저장·재분류하지 않는다.
- 통합 설명은 클릭 없이 포함되고 다른 해석의 추가·취소와 문장 수정 결과가 보고서에 반영된다.
- 첨부된 두 보고서 묶음의 시각적 구조가 실제 데이터로 나타난다.
- PDF에서 한글, 색상 막대, 원형 마커와 긴 문장이 정상 출력된다.
