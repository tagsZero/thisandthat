# PDF 한글 폰트

Noto Sans CJK KR Regular / Bold 원본 OTF를 함께 배포한다. 앱은 이 로컬 자산을 PDF용 HTML의 data URL로 전달한다. Windows 시스템 폰트·외부 CDN을 사용하지 않는다. 폰트를 임의로 수정하거나 이름을 바꾸지 않았다.

- 원본: https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/Korean
- Regular: https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/OTF/Korean/NotoSansCJKkr-Regular.otf
- Bold: https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/OTF/Korean/NotoSansCJKkr-Bold.otf
- 라이선스 원본: https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/LICENSE
- 라이선스: SIL Open Font License 1.1, 동봉한 `OFL.txt` 전문을 유지한다.
- 준비일: 2026년 10월 21일 (한국 시간)

재다운로드 시 위 해시와 대조한다. 상류 `main`의 변경본을 자동 교체하지 않는다. Windows 실제 PDF를 검증했으며 Linux 실제 출력은 아직 확인하지 않았다.
